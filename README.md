# inventory-management
reinvent and manage all an inventory needs with Go & Mongo

commands to run on local

GET : 


curl -X GET http://localhost:3000

POST:


curl -X POST http://localhost:3000/new/Chocolate/10/100

curl -X POST http://localhost:3000/erase/Chocolate

curl -X POST http://localhost:3000/update_cost/Chocolate/125

curl -X POST http://localhost:3000/update_qty/Chocolate/125
